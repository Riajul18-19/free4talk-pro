## ✨ Features

- **💬 Saved Chats**: Save and search chat conversations across all the rooms you join. View past chats or bring previous messages into your current room.
- **✉️ Direct Message (DM) History**: Automatically archive direct messages on your device so they outlive Free4Talk's 7-day limit.
- **🎵 Spotify Player**: Connect Spotify and stream playlists directly to everyone in your Free4Talk room.
- **📺 YouTube Remote**: Link any YouTube tab to play videos in sync with your room, with queue and repeat controls.
- **⏱️ Who's Talking / Room Timer**: Live speaking time tracking and breakdown of who has spoken the most in the room.
- **👋 Welcome Messages**: Automatically greet friends or newcomers who enter your rooms with customized messages.
- **🛡️ Auto Kick**: Protect your rooms by auto-kicking unverified users or specific blocked profiles the moment they join.
- **💎 Fully Unlocked & Free**: All Pro capabilities unlocked without paywalls or subscriptions.

## 🚀 Installation

### Option 1: Download Pre-built Release (.zip)
1. Download the latest `free4talk-pro-v1.0.0.zip` from [Releases](https://github.com/Riajul18-19/free4talk-pro/releases).
2. Unzip the downloaded file to a folder on your computer.
3. Open Chrome or any Chromium-based browser (Brave, Edge, Opera, Vivaldi).
4. Go to `chrome://extensions`.
5. Enable **Developer mode** via the toggle switch in the top-right corner.
6. Click **Load unpacked** in the top-left corner and select the extracted folder.
7. Pin **Free4talk Pro** to your toolbar!

### Option 2: Clone with Git
1. Clone this repository:
   ```bash
   git clone https://github.com/Riajul18-19/free4talk-pro.git
   ```
2. Follow steps 3–7 above, selecting the cloned directory.
